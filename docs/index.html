Abstract

Electricity prices in ERCOT, the Texas grid, are strongly heavy-tailed. Most hours trade near a median of about $21/MWh, while a small number of grid-stress hours run toward the $9,000/MWh regulatory cap, and renewable oversupply can push prices negative. The economics of the market are therefore set by rare events rather than by typical conditions.

This project asks whether multimodal signals, and news sentiment in particular, improve next-hour forecasts of the ERCOT real-time hub-average price. Eight data sources, namely real-time and day-ahead prices, system load, weather across five zones, natural gas prices and storage, nuclear reactor outages, and GDELT news sentiment, are assembled into an hourly matrix of 77,956 observations and 87 engineered features covering 2016 through 2024. Thirteen model configurations are benchmarked under one strictly chronological split, spanning gradient-boosted trees, deep sequence models, zero-shot time-series foundation models, classical statistical baselines, and hybrids of the two.

The strongest configuration is neither purely supervised nor purely zero-shot. Feeding a frozen Chronos forecast into XGBoost as a single additional feature yields a mean absolute error of $12.13/MWh and 61.4% spike recall on the held-out 2024 test year, ahead of the best standalone supervised model at $13.75/MWh. Removing sentiment features degrades accuracy, and the direction of that effect reproduces from this codebase, though the published margin does not - a discrepancy documented rather than smoothed over.

Method

The hybrid keeps the two halves of the problem separate. Chronos (amazon/chronos-t5-small) sees only the raw price series: a 512-hour context window, from which it forecasts one hour ahead. It is never fine-tuned. That single forecast is appended to the 87 engineered features as a column named chronos_pred, and XGBoost trains on the 88-column result, learning when the univariate forecast deserves trust and when weather, outage, gas, and sentiment features should override it.

Every model shares one chronological split, with no shuffling: training on 2016 through 2022, validation on 2023, and testing on 2024. The test year contains 8,767 hours, of which 114 exceed the $200/MWh spike threshold.

Key Findings

  1. The best model is neither purely supervised nor purely zero-shot. Chronos contributes a univariate temporal forecast; XGBoost contributes the physical, market, weather, outage, and sentiment context. Together they reach $12.13/MWh MAE, ahead of either component alone.
  2. CatBoost is the strongest standalone model at $13.75/MWh, and gradient-boosted trees as a family handle ERCOT's nonlinear interactions better than the deep models tested here.
  3. News sentiment carries signal. GDELT tone is the highest-gain single feature in the 87-feature model, and removing the sentiment family degrades MAE in every configuration tested.
  4. Deep learning underperformed. The LSTM is competitive on MAE but misses most spikes, and the Temporal Fusion Transformer records zero spike recall on 2024. Spike behaviour is rare and event-driven, which suits trees and hurts models that need many examples of the phenomenon.
  5. Spike prediction is a tradeoff, not a single score. Recall and precision trade off sharply across models, so the useful question is which operating point a given application needs.

Reproducibility

The repository ships the canonical feature matrix, so a fresh clone can train and evaluate without re-pulling any primary source or holding any API key: 

git clone https://github.com/rohanfozdar/Electricity-Spot-Price-Forecaster.git
cd Electricity-Spot-Price-Forecaster
pip install -e .
python run_full_pipeline.py --stage models

Two caveats are stated plainly rather than buried. First, the published no-sentiment ablation figure of $34.53/MWh does not regenerate from this codebase: re-running it four ways, across two feature matrices with and without the log1p transforms, puts that number between $22.17 and $24.58 every time. The conclusion survives, since a like-for-like comparison still shows sentiment reducing MAE by 22.0%, but the specific published pair should be read as the paper's record. Second, the Chronos backfill required for the hybrid is roughly 77,400 forward passes and has not yet been completed end-to-end on the machine used to prepare this repository, so the headline $12.13/MWh is likewise the paper's record. The script that reproduces it, models/train_chronos_hybrid.py, checkpoints and resumes.

Seven of the thirteen configurations, namely CatBoost, NGBoost, LSTM, TFT, TimesFM, Prophet, and SARIMAX, were verified by code inspection rather than re-executed for this release, and the runtime estimates in the repository README are approximate.
